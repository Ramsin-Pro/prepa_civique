*Généré le 31 octobre 2026 à partir de `apps/api/content/nat/` (`npm run relecture -w api`). Ces questions arrivent au statut « à relire » : aucune n’est publiée sans relecture humaine.*

Les énoncés officiels sont repris mot pour mot de la liste du ministère (258 énoncés). Les énoncés déjà présents dans une autre liste ne sont pas rédigés ici : la question existante leur est rattachée. Les propositions, les bonnes réponses, les explications et les sources ont été rédigées avec assistance : elles doivent être relues par une personne compétente avant publication (cahier des charges §7).
